# Motivara
## Fitness Tracking, Coaching & Community

Motivara is a web application designed to help users connect their fitness tracker, work with certified personal trainers, monitor progress, and stay motivated through a supportive fitness community.

The platform is designed for:
- Beginners
- Athletes
- Personal trainers

## What Is Motivara?

Motivara brings fitness tracking, personalised coaching, and community support into one platform. Users can connect their Strava account, receive tailored workout plans, communicate with personal trainers, and prepare for events such as marathons alongside like-minded people.

## How to Run the App

### Step 1: Install the Requirements
```bash
pip install -r requirements.txt
```

### Step 2: Run the App
```bash
python run.py
```
Then open `http://127.0.0.1:5000` in your browser.

### Step 3: Generate Documentation
```bash
pdoc fitness_app
```

### Step 4: Run the Tests
```bash
pytest
```
